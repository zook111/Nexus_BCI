# Nexus BCI

Created and maintained by **[zook111](https://github.com/zook111)**.

Nexus is a local EEG acquisition, experiment and learning workspace for OpenBCI hardware. The initial application release and setup documentation are being prepared in a review pull request.

Source code will be released under the MIT licence with attribution to zook111. Bundled media provenance and redistribution notices will accompany the application.
